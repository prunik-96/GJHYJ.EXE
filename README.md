## aegis — статический анализатор

Анализатор кода на Python, который ищет уязвимости и ошибки без нейросетей:
разбор в синтаксическое дерево, граф потока управления, анализ потока данных
и набор правил по образцу. Зависимостей нет — только стандартная библиотека.

```bash
python -m aegis .                  # проверить проект
python -m aegis --list-rules       # каталог из 34 проверок
```

Есть необязательная связка с Claude: модель предлагает исправления, а
анализатор их проверяет и отклоняет всё, что не выдерживает проверку —
включая попытки заглушить находку комментарием или вырезать код вместе
с проблемой.

```bash
python -m aegis app.py --ai-fix    # проверенные исправления
python -m aegis . --ai-triage      # разбор находок
```

Подробное описание архитектуры — в [`aegis/README.md`](aegis/README.md).
